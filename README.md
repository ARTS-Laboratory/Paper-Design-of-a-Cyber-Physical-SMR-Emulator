# Paper-Design-of-a-Cyber-Physical-SMR-Emulator

This is the companion repository for the ASME journal paper, *Design and Experimental Validation of a Cyber-Physical SMR Emulator for Digital Twin-Based Control via Time-Constant Synchronization*.

This repository contains the models, code, and paper-specific artifacts associated with the manuscript. For the physical thermal-loop testbed and related hardware resources, see the companion repository: [CORE²S](https://github.com/ARTS-Laboratory/core2s). Testing for this current paper was done on the test loop in the spring of 2026. Subsequent updates have been made to the test loop.
